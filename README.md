# Compass — Collapsible Sidebar

A collapsible sidebar navigation built for **Compass**, a concept student
resource hub for KNUST students. Built for the Elevvo Frontend Web
Development Track (Level 1, Task 1).

## Features
- Logo + 5 navigation links (Dashboard, Course Notes, Find a Tutor, Events,
  Settings), each with an inline SVG icon
- Toggle button collapses the sidebar to an icon-only rail with a smooth
  CSS transition
- Active link indicated with a left accent bar
- Collapsed/expanded state is remembered via `localStorage`

## Bonus implemented
- **Mobile responsive**: below 768px the sidebar becomes a fixed bottom
  tab bar instead of a side rail

## Tech
HTML, CSS, JavaScript (no frameworks or libraries)

## Run it
Open `index.html` directly in a browser, or serve the folder with the
VS Code "Live Server" extension.
